# هویت بصری آمرز

همه فایل‌ها با `generate.py` ساخته شده‌اند و **متن‌ها به مسیر برداری تبدیل شده‌اند** —
یعنی چاپخانه به فونت وزیرمتن نیاز ندارد و حروف فارسی هیچ‌وقت به‌هم نمی‌ریزند.

**معادل CMYK برای چاپ** (تقریبی — از چاپخانه بخواهید با نمونه تطبیق دهد):
سبز اصلی `C62 M35 Y53 K35` · طلایی `C20 M30 Y65 K5`

## فونت

**وزیرمتن** — رایگان و متن‌باز. سایت از همین فونت استفاده می‌کند.
برای طراحی‌های جدید از [github.com/rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) دانلود کنید.

## فایل‌ها

### لوگو

| فایل | کاربرد |
|---|---|
| `logo-horizontal.svg` / `.png` | حالت اصلی — سربرگ، کارت ویزیت، امضای ایمیل |
| `logo-horizontal-white.svg` / `.png` | روی زمینه تیره |
| `logo-mark.svg` / `.png` | فقط نشان — پروفایل اینستاگرام، فاوآیکون، مهر |
| `logo-mark-mono.svg` | تک‌رنگ — برای مهر، حکاکی و چاپ تک‌رنگ |

**قواعد استفاده:** نسبت‌ها را تغییر ندهید، رنگ‌ها را عوض نکنید، دور لوگو حداقل به اندازه
یک گلبرگ فضای خالی بگذارید، و روی تصویر شلوغ قرارش ندهید.

### برچسب بسته‌بندی

| فایل | اندازه | کاربرد |
|---|---|---|
| `label-round-50mm.pdf` | دایره ۵۰ میلی‌متر | روی پک میوه، ظرف حلوا، جعبه خرما |
| `label-round-50mm-dark.pdf` | همان، زمینه سبز | وقتی بسته‌بندی روشن است و می‌خواهید دیده شود |
| `label-rect-60x30mm.pdf` | ۶۰ × ۳۰ میلی‌متر | روی ظروف مستطیلی، لیوان، جعبه شیرینی |
| `label-rect-60x30mm-dark.pdf` | همان، زمینه سبز | — |

هر فایل **۲ میلی‌متر نشت رنگ (bleed)** از هر طرف دارد؛ یعنی طرح کمی بزرگ‌تر از اندازه
نهایی است تا بعد از برش، لبه سفید نماند. به چاپخانه بگویید «با بلید طراحی شده».

**پیشنهاد شروع:** ۱۰۰۰ عدد برچسب دایره‌ای ۵۰ میلی‌متری روی کاغذ گلاسه با روکش مات.
ارزان است، تیراژ حداقلی ندارد و همین امروز قابل سفارش است.

### روبان تاج گل

`ribbon-1500x100mm.pdf` — قالب ۱۵۰ × ۱۰ سانتی‌متر، خوابیده (همان‌طور که چاپ می‌شود).

سمت راست بلوک برند است و بقیه فضا برای متن تسلیت خالی مانده. عبارت خاکستری
«متن تسلیت اینجا نوشته می‌شود» راهنماست و باید در فایل نهایی حذف یا جایگزین شود.

## به‌روزرسانی شماره تلفن

شماره‌ای که روی فایل‌هاست **نمونه** است. برای عوض کردنش:

```bash
# مقادیر بالای فایل را ویرایش کنید
nano brand/generate.py     # PHONE و SITE

python3 brand/generate.py  # همه فایل‌ها دوباره ساخته می‌شوند
```

پیش‌نیازهای اجرا (یک‌بار):

```bash
pip install fonttools brotli uharfbuzz cairosvg
npm i @fontsource/vazirmatn
# فایل‌های woff2 را به ttf تبدیل و در ~/.fonts بگذارید (توضیح در ابتدای generate.py)
```

اگر پایتون در دسترس نداری، فایل‌های SVG را در Illustrator یا Inkscape باز کن و متن را
دستی عوض کن — چون متن به مسیر تبدیل شده، باید کادر متن را پاک و دوباره تایپ کنی.

## نکته‌ای که موقع طراحی برچسب مهم است

کارت محصول در سایت روی موبایل حدود ۳۵۰ پیکسل عرض دارد. وقتی از بسته‌بندی برچسب‌خورده
عکس می‌گیری، **لوگو باید در همان اندازه خوانا باشد**. پیش از سفارش تیراژ بالا، یک نمونه
چاپ کن، روی بسته بچسبان، عکس بگیر و روی گوشی نگاه کن.
